# 404 — Page not found

## Purpose

Shown when a visitor opens an address that does not exist or has been moved. It
keeps them on the site instead of leaving them at a browser error.

## Sections, in order

1. **Large "404"** on a faint dot-grid background that fades out towards the edges.
2. **Message** — "Page not found" and a sentence explaining what happened.
3. **Two buttons** — go to the home page, or go back to the previous page.

The site header and footer are deliberately hidden here, so the page stays a single
full-screen view.

## Key interactions

- "Go home" opens the home page
- "Go back" returns to the previous page in the visitor's history

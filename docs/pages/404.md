# 404 — Page not found

## Purpose

Shown when a visitor opens an address that does not exist or has been moved. It
keeps them on the site, with the full menu, instead of leaving them at a browser
error.

## Sections, in order

1. **Header** — the same name and menu as every other page.
2. **"404" stamp** — a round red stamp, like the one on the coffee labels, that
   presses on once when the page loads (it just appears for visitors who reduce motion).
3. **Message** — the heading "Page not found" and a sentence suggesting where to
   go next.
4. **Three buttons** — "Go to the home page" (the main button), "Read the blog"
   and "Contact us".
5. **Footer** — the same footer as every other page, with the contact details and
   the "Demo project — fictional business" label.

## Key interactions

- With analytics accepted, the page sends a `page_not_found` event to Google Analytics, so broken
  links (an old WordPress address without a redirect, a typo in a link) show up in GA with the
  missing address and where the visitor came from.

- "Go to the home page" opens the home page
- "Read the blog" opens the blog
- "Contact us" opens the contact page
- The menu and the footer links work as on any other page
